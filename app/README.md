# Lume — Expo Client

The React Native front-end for Lume, built with Expo Router (file-based routing). All user data is stored on-device via MMKV — no database, no auth.

## Overview

Single-binary Expo app that covers the full user journey: onboarding → daily food logging via camera → workout logging via text → history review.

## Folder Structure

```
app/
├── app/                    # Expo Router route tree
│   ├── _layout.tsx         # Root layout — gates to onboarding if no profile
│   ├── onboarding.tsx      # 3-step onboarding (name → body → goal)
│   └── (tabs)/             # Tab navigator: Today, Log, Move, History
├── components/             # Shared UI primitives
├── lib/                    # Business logic, storage, and API calls
├── dist/                   # Static web export (generated, do not edit)
├── app.json                # Expo project config (name, slug, icons)
├── babel.config.js         # Babel preset for Expo
├── expo-env.d.ts           # Expo TypeScript ambient types
├── package.json            # Dependencies and scripts
└── tsconfig.json           # TypeScript config (extends expo/tsconfig.base)
```

## Dependencies

| Package | Purpose |
|---------|---------|
| `expo` | Core Expo SDK + Metro bundler |
| `expo-router` | File-based navigation |
| `react-native-mmkv` | Fast on-device key-value storage |
| `@supabase/supabase-js` | Edge function invocation (no DB/auth) |
| `expo-camera` / `expo-image-picker` | Meal photo capture |
| `expo-blur` | Frosted-glass tab bar |
| `expo-haptics` | Tactile feedback on shutter |
| `expo-file-system` | Base64 encoding of photo URIs |

## Usage

```bash
npm install
cp .env.example .env   # fill in EXPO_PUBLIC_SUPABASE_URL + EXPO_PUBLIC_SUPABASE_ANON_KEY
npx expo start         # opens Expo Go / simulator
```

## Notes

- All food and workout logs are capped at 2 000 entries in MMKV; older entries are silently dropped.
- The `dist/` folder is a static web export — it is generated by `npx expo export --platform web` and should not be committed in production workflows.
- To fully reset the app, delete and reinstall it (no server-side data to clear).
